# terradash provider

Manages Grafana dashboards as typed HCL. Guides: [converting dashboards](guides/converting-dashboards), [writing dashboards](guides/writing-dashboards).

- Uses Grafana's classic dashboards API; v2 schema dashboards are unsupported. Tested with Grafana 13.
- Requires Terraform or OpenTofu with plugin protocol 6.

## Example usage

```terraform
provider "terradash" {
  url  = "https://grafana.example.com"
  auth = var.grafana_token
}

variable "grafana_token" {
  type      = string
  sensitive = true
}
```

Environment only: `provider "terradash" {}`.

## Authentication

`auth` is one of:

- service account token (bearer),
- `user:password` (basic; `org_id` selects the organization),
- `anonymous`.

Prefer `GRAFANA_AUTH` over hard-coding `auth`.

## Environment variables

| Argument | Variable |
| --- | --- |
| `url` | `GRAFANA_URL` |
| `auth` | `GRAFANA_AUTH` |
| `org_id` | `GRAFANA_ORG_ID` |
| `ca_cert` | `GRAFANA_CA_CERT` |
| `insecure_skip_verify` | `GRAFANA_INSECURE_SKIP_VERIFY` |

Arguments override variables.
